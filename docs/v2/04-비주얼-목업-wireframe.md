**v1 → v2 매핑**:

- 우측 도크 (Session Parameters) → ② Inspector (선택한 timepoint 의 속성만)
- View 메뉴 토글 4개 → 좌 icon-bar (모드 전환) + Inspector 자동 표시

**핵심 변화**:
1. 도크 4개 → 영역 3개 (icon-bar / context-panel / main+inspector). 토글 함정 ↓
2. timepoint 클릭 = inspector 자동 (Figma 패턴). 사용자가 매번 어디 봐야할지 모르는 문제 ↓
3. 그래프 위 keyboard 단축키 (I/O/[ ]) — Audacity·Premiere 영감
4. 색은 condition 별 자동 팔레트 (OHIF Viewer 영감) — 그래프·트리·표 모두 일관

## 인터랙션 디테일 (변경된 부분만)

| v1 | v2 |
|---|---|
| timepoint 추가 = + Add 버튼 | 그래프 위 빈 영역 더블클릭 + 단축키 Cmd+T |
| timepoint 삭제 = ✕ + 확인 dialog | 인스펙터 안 휴지통 + Cmd+Backspace + Undo (Cmd+Z) |
| Apply = 명시적 버튼 | 변경 시 라이브 미리보기 + Apply 또는 Cmd+Return |
| Min/Peak override = checkbox 체크 + spinbox | 그래프 위 핸들 직접 잡기 (현재도 됨) + lock 토글 |
| 결과 비교 = TTE comparison 미니 그리드 | Compare 모드의 메인 화면 |
| Export = 우하단 버튼 3개 | Export 모드 + Cmd+E |
| 페이지 전환 = 상단 탭 (NIRS/HRV) | icon-bar (모드별) + Cmd+1/2/3 |
| 도크 토글 | (없음) — 영역 고정, Inspector 자동 |
