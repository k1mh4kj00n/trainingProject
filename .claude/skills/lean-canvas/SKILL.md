# 린 캔버스 작성

사용자가 제시한 아이디어를 Ash Maurya의 Lean Canvas 프레임워크에 따라 9개 블록으로 작성한다.

## 작성할 9개 블록

1. **문제(Problem)**
   - 타겟 고객이 겪는 상위 3가지 문제
   - 현재 사용 중인 기존 대안(workaround) 명시
   - 각 문제의 심각도 (1~10)

2. **고객 세그먼트(Customer Segments)**
   - 메인 타겟 고객
   - 얼리 어답터 (가장 절실한 사람들)
   - 인구통계학적, 행동적 특성

3. **고유 가치 제안(Unique Value Proposition)**
   - 한 문장 차별화 메시지
   - 하이 레벨 컨셉 ("X for Y" 형식)

4. **솔루션(Solution)**
   - 각 문제에 대응하는 핵심 기능 3개
   - MVP 범위에 들어갈 기능만

5. **채널(Channels)**
   - 한국 시장 기준 초기 고객 도달 경로
   - 예: 인스타그램, 당근, 에브리타임, 디시인사이드, 블라인드 등
   - 무료/유료 채널 구분

6. **수익 흐름(Revenue Streams)**
   - 가격 모델 (구독/일회성/거래수수료/광고 등)
   - 가격대 (원화 기준)
   - LTV 추정

7. **비용 구조(Cost Structure)**
   - 월 고정비 (서버, 인건비, 도구 등)
   - 변동비 (CAC, 결제 수수료 등)
   - 손익분기점 추정

8. **핵심 지표(Key Metrics)**
   - North Star Metric 1개
   - 보조 지표 3~4개
   - 측정 방법 명시

9. **압도적 우위(Unfair Advantage)**
   - 쉽게 복제할 수 없는 경쟁 우위
   - 없다면 "현재 없음, 확보 방안 필요"라고 솔직히 표시

## 출력 규칙

- 한국어로 작성, 마크다운 표 형식 사용
- 모든 가정에는 `[가정]` 태그 표시
- 검증 가능한 사실에는 `[사실]` 태그 (출처 포함)
- 결과를 `./docs/린캔버스-lean-canvas.md` 파일로 저장
- 마지막에 "검증이 필요한 상위 3가지 가정"을 별도 섹션으로 정리

## 출력 후 액션

작성 완료 후 사용자에게 다음 단계를 제안:
- "다음 단계로 페르소나 작성(/persona) 또는 아이디어 검증(/validate-idea)을 권장합니다."
