# 경쟁사 분석 (3단계 체인)

## 1단계: 경쟁사 식별 및 포지셔닝 추출

다음 4가지 유형의 경쟁사를 각각 식별한다:

1. **직접 경쟁자 (Direct)**: 동일 문제, 동일 솔루션
2. **간접 경쟁자 (Indirect)**: 동일 문제, 다른 솔루션
3. **대체재 (Substitutes)**: 우회책으로 사용되는 모든 것 (예: 엑셀, 종이, 수기)
4. **잠재 진입자 (Potential)**: 인접 영역에서 진입 가능한 플레이어

총 5~8개 경쟁사를 선정하고 각각에 대해:
- 회사명, URL
- 타겟 고객
- 핵심 가치 제안 한 문장
- 가격 모델
- 추정 매출/사용자 규모 (한국 시장 기준)
- 강점 3가지
- 약점 3가지

**한국 경쟁사를 우선적으로 포함**할 것. 글로벌 사례는 비교 참조용으로만.

## 2단계: 포지셔닝 맵

2축 매트릭스로 시각화:
- X축, Y축은 카테고리에서 가장 의미 있는 두 가지 차원 선택
  - 예: 가격(저가↔고가) × 기능 깊이(단순↔복잡)
  - 예: 타겟(B2C↔B2B) × 자동화 정도(수동↔자동)
- ASCII 또는 Mermaid 다이어그램으로 표현
- 각 경쟁사 위치 표시
- "현재 비어있는 공백 영역" 명시

## 3단계: 전략 도출

다음 3가지를 도출:

### 공격 영역 (Attack Zones)
경쟁사 약점 + 우리 강점이 겹치는 2개 영역. 여기에 집중해야 한다.

### 회피 영역 (Avoid Zones)
경쟁사 강점이 압도적인 1개 영역. 정면 승부를 피해야 한다.

### 공백 영역 (White Space)
아무도 점유하지 않은 1개 기회 영역. 위험하지만 큰 기회.

## 출력 형식

```markdown
# 경쟁사 분석: [카테고리명]

## 시장 개요
[시장 규모, 성장률, 주요 트렌드 3줄 요약]

## 경쟁사 매트릭스
[표]

## 포지셔닝 맵
[다이어그램]

## 전략적 시사점
### 공격 영역
### 회피 영역
### 공백 영역

## 우리의 차별화 전략 (제안)
[3~5문장 결론]
```

## 출력 규칙

- 한국어로 작성
- 결과를 `./docs/경쟁사분석-competitors.md`로 저장
- 모든 추정치에 `[가정]` 또는 `[추정]` 태그
- 출처 가능한 정보는 출처 명시 (또는 "검증 필요" 표시)
